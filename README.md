# Lizoňová Lab: Drug Delivery and Controlled Release

Webová stránka výskumnej skupiny Ing. Denisy Lizoňovej, PhD. (Ústav chemického inženýrství, VŠCHT Praha).

- `index.html` – celá stránka (text, zoznamy ľudí, publikácií, noviniek sú v JavaScriptových poliach v spodnej časti súboru)
- `photos/` – fotografie

Stránka sa zverejňuje cez GitHub Pages (Settings → Pages, vetva `main`, priečinok `/`).
